# Cubeforge Docs

Documentation site for [Cubeforge](https://github.com/1homsi/cubeforge) — a declarative 2D browser game engine built with React.

Built with [VitePress](https://vitepress.dev).

## Dev

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
